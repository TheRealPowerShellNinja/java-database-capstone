# User Stories

## Admin User Stories

1. As an admin, I want to log into the portal, so that I can manage the platform securely.
2. As an admin, I want to log out of the portal, so that I can protect system access.
3. As an admin, I want to add doctors to the portal, so that they can use the system.
4. As an admin, I want to delete doctor profiles from the portal, so that outdated records are removed.
5. As an admin, I want to run a stored procedure to view appointments per month, so that I can track usage statistics.

---

## Patient User Stories

1. As a patient, I want to view a list of doctors without logging in, so that I can explore available options.
2. As a patient, I want to sign up using my email and password, so that I can book appointments.
3. As a patient, I want to log into the portal, so that I can manage my bookings.
4. As a patient, I want to log out of the portal, so that I can secure my account.
5. As a patient, I want to book an hour-long appointment with a doctor, so that I can receive medical consultation.
6. As a patient, I want to view my upcoming appointments, so that I can prepare accordingly.

---

## Doctor User Stories

1. As a doctor, I want to log into the portal, so that I can manage my appointments.
2. As a doctor, I want to log out of the portal, so that I can protect my data.
3. As a doctor, I want to view my appointment calendar, so that I can stay organized.
4. As a doctor, I want to mark my unavailability, so that patients only see available time slots.
5. As a doctor, I want to update my profile with specialization and contact information, so that patients have accurate information.
6. As a doctor, I want to view patient details for upcoming appointments, so that I can be prepared.
